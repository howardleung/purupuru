# Branding status

PuruPuru is the current product name and public-facing identity. The repository keeps technical package scopes and database identifiers generic so branding changes do not require data-model or import rewrites.

The current bag-and-droplet mark is a temporary project asset used for the application icon and wordmark treatment. Domain, trademark, and final visual-identity review remain owner responsibilities before broader commercial use.

Brand changes must not rename credentials, provider resource IDs, database identities, migrations, or environment variables merely for presentation consistency. External provider names and domains are managed outside this repository.
